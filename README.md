# Khushi Portfolio (React)

Premium freelancer portfolio rebuilt with a modern React stack.

## Stack

- **Vite** — fast dev server & build
- **React 19** + **TypeScript**
- **React Router** — multi-page navigation
- Same design system CSS as the original site

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Project structure

- `src/pages` — Home, About, Services, Projects, Contact
- `src/components` — Header, Footer, layout, cursor, video project card
- `src/data` — content & contact details
- `public/assets` — images, video, logo
- `legacy-static` — previous HTML/CSS/JS version (reference only)
